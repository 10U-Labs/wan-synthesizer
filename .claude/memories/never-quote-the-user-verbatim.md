# Never quote the user verbatim

Never record the user's words verbatim, anywhere: not in a memory, an issue, a commit message, a task, a summary or a compaction. Write what the user meant in your own words.

**Why:** the user asked in `10ulabs.com` on 2026-10-06 for the verbatim quotes to be purged from its memories and for none to be recorded again, and `deltahdl` holds the same rule as `user-words-are-never-recorded-verbatim`. A paraphrase keeps the rule and its reason; the exact wording adds nothing a later session needs. Adopted here on 2026-10-07 under issue #255, which also removed the one quotation this rulebook held.

**How to apply:** when a memory's **Why:** line cites a correction, say what the user held and why, with no quotation marks around their words. Quoting a command, a file's content, a commit message or a session's own wording is still fine; only the user's speech is paraphrased.
